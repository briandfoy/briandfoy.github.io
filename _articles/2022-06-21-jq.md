My `jq` cheatsheet:

<!--more-->

Access the top level:

{% highlight text %}
jq .
{% endhighlight %}

Pretty print:

{% highlight text %}
jq -r .
{% endhighlight %}

List the top-level keys:

{% highlight text %}
jq -r ".|= keys'
{% endhighlight %}

Access an object key:

{% highlight text %}
jq .keyname
{% endhighlight %}

Access an array element:

{% highlight text %}
jq .[n]
{% endhighlight %}

Access an array range:

{% highlight text %}
jq .[n:m]
jq .[n:]
jq .[:m]
{% endhighlight %}

Access multiple object values:

{% highlight text %}
jq '.first, .second'
{% endhighlight %}

Access a value then filter:

{% highlight text %}
jq '.[n] | .first, .second'
{% endhighlight %}

Map an array

{% highlight text %}
jq 'map(...)'
{% endhighlight %}
